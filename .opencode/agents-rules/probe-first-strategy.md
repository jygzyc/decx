## Probe-First Strategy

- Probe the target environment or DECX surface before building a large theory.
- Each loop solves one immediate uncertainty: observe, focus, test, record.
- Prefer high-signal, low-cost queries: manifest, exported components, AIDL, xrefs, method context, CFG, resource lookup.
- Do not read every sibling component when one exact trace is enough.
- If a probe contradicts the plan, write or request a hint instead of forcing the old plan.
