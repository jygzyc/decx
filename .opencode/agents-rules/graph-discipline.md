## Graph Discipline

- Graph writes must use the fixed DECX function for the active role; there is no generic command writer.
- The proof chain is `Fact -> Intent -> Fact`.
- The correction chain is `Hint -> Intent -> Fact` or `Hint -> Planner decision`.
- Hints are control input, not evidence. Planner must answer open hints before ordinary work.
- Open hints freeze Explorer output. Explorer can renew a lease but cannot add candidates or conclude intents until Planner responds.
- Explorer cannot fail intents. Evaluator cannot fail intents. Planner can fail an intent only with accepted fact evidence.
- Public manual link writing is not exposed; provenance links are generated by graph functions.
- Accepted facts are the only positive truth source for downstream reasoning.
- Use raw graph chains for debugging and accepted-only proof chains for conclusions.
