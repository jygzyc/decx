# App Cloud Control Analysis Knowledge Index

Use this profile for apps that receive behavior, routing, configuration, policy, or command decisions from cloud services.

| Topic | Load when |
|---|---|
| `cloud_control` | Remote config, feature flags, command channels, policy JSON, task dispatch, AB testing, update/plugin control, or backend-driven WebView/Intent behavior |
| `evidence` | Candidate review, impact gate, severity, and rejection decisions |
